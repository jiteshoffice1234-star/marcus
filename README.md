# MARCUS

A production-quality accounting education app that takes a learner from
**accounting zero → basic → intermediate → professional accountant → advanced
accounting → CA Final level**.

The core learning loop:

**LEARN → UNDERSTAND → PRACTICE → TEST → ANALYZE → REVISE → MASTER**

> This app provides accounting education and CA-level learning content. It is
> not affiliated with the Institute of Chartered Accountants of India (ICAI)
> and does not confer any professional qualification. Official ICAI syllabus
> and qualification requirements are separate and must be satisfied through
> ICAI processes.

## Features

- **Personalized onboarding** — a 25-question knowledge assessment maps your
  strengths and weaknesses, recommends your starting level, and builds a
  personalized roadmap.
- **Curriculum** — 4 levels (Foundation → Professional → Advanced → CA Final),
  each with subjects, chapters, topics, and full lessons with worked examples
  and common mistakes.
- **Practice engine** — MCQ, numerical, journal entry, fill-in-the-blank, and
  true/false questions with a full answer experience (why you're right/wrong,
  common mistakes, related concepts).
- **Exams** — topic, chapter, level, mixed, professional, and CA Final mock
  tests with timers, negative marking, review marking, and detailed results.
- **Accounting simulator** — journalize real transactions for fictional
  companies; the underlying ledger, trial balance, P&L, and balance sheet are
  computed for real and checked against your entries.
- **Mistake intelligence & smart revision** — every wrong answer is recorded;
  weak areas generate revision (Day 1 → 3 → 7 → 14 → 30 spaced repetition).
- **AI tutor** — ask questions, get level-adapted explanations, check your
  journal entries (provider-abstracted; the built-in coach works offline).
- **Reference library, notes, bookmarks, search, achievements, streaks, ranks** —
  professional gamification (XP, ranks, badges).
- **Offline-first** — the full MVP curriculum is bundled; learner progress is
  persisted locally and synced to Supabase when configured.
- Light/dark themes, responsive layouts (mobile / tablet / web).

## Tech stack

- **Frontend:** Flutter (modular architecture: `core/`, `features/`, `data/`,
  `domain/`, `shared/`)
- **Backend:** Supabase (PostgreSQL, Auth, RLS) — optional; the app runs fully
  locally without it. Schema and migrations live in `supabase/migrations/`.
- **AI:** abstraction layer (`AiTutorService`) with a built-in offline coach and
  a remote provider option selected via `--dart-define`.

## Build the Android APK

Prerequisites: Flutter SDK (stable) installed and on your PATH, Android SDK.

```bash
flutter pub get
flutter build apk --release
```

The APK is written to `build/app/outputs/flutter-apk/app-release.apk`.
To sign it for direct install, configure `android/key.properties` (see
`android/app/build.gradle.kts`) or build a debug APK with:

```bash
flutter build apk --debug
# → build/app/outputs/flutter-apk/app-debug.apk
```

## Run locally

```bash
flutter run            # device / emulator
flutter run -d chrome  # web
flutter test           # run the test suite (57 tests: accounting engine, assessment, revision, gamification, repositories, widgets)
```

## Project layout

```
lib/
  core/      config, theme, routing, errors, storage, networking, utils
  domain/    pure-Dart engines (accounting, assessment, revision, gamification)
  data/      models, datasources, repositories, sync
  features/  auth, onboarding, home, learn, practice, exams, simulator,
             ai_tutor, profile, search, reference
  shared/    design-system widgets
assets/data/ curriculum + question content (database-driven, editable JSON)
supabase/    database schema, migrations, RLS
tool/        icon generator, project-local Flutter launcher
```

## Branding

The app name is centralized in `lib/core/config/app_config.dart`. Platform
launcher names live in `android/app/src/main/AndroidManifest.xml`,
`ios/Runner/Info.plist`, and `web/manifest.json`. Original icon assets are
generated by `tool/icon_generator.js` into `assets/branding/icon/`.
